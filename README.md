# Heddy Satria — Portfolio

Personal portfolio showcasing selected software development, testing, data analytics, business intelligence, and UX/UI projects.

Built with HTML, CSS, and vanilla JavaScript for static deployment on GitHub Pages.

## Structure

- `index.html` — public portfolio content
- `css/` — theme, layout, motion, and responsive rules
- `js/main.js` — image loading, navigation, active-section tracking, tabs, and reveal effects
- `assets/` — favicon and project screenshots

## Local preview

Open `index.html` directly in a browser or serve the directory with VS Code Live Server.

## Updating content

Public content is maintained in `index.html`. Theme colours and layout values are defined as CSS custom properties near the top of `css/styles.css`.

Project screenshots are stored in `assets/projects/` and referenced by their existing PNG or JPG filenames.

## GitHub Pages

After publishing the `heddysatria.github.io` repository, open **Settings → Pages**, choose **Deploy from a branch**, and select the root of the default branch. The expected site address is `https://heddysatria.github.io/`.
